# Retail Sales & Profitability Analysis | SQL

## Data Cleaning
The project begins by identifying and correcting data-quality issues within the retail dataset.

Examples:
1. Leading and trailing spaces
2. Inconsistent capitalization
3. Missing values
4. Inconsistent category and location data
5. Invalid quantities
6. Duplicate records

Data was cleaned and standardized before being used in the analytical queries. 
<b>Note</b>: The queries were ran seperately, but I kept them in the same file for presentation.
